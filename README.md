# 과제 관리 칸반 보드

칸반 보드 오픈소스를 대학생 과제 일정 관리용으로 고친 프로젝트입니다.
오픈소스 스튜디오 팀 프로젝트 1조 (김근원 이준형)

배포 주소: https://kanban-board-pink-eight.vercel.app/

## 원본 오픈소스

https://github.com/aman162000/kanban-board (MIT License)

## 실행 방법

```
npm install --legacy-peer-deps
npm run dev
```

## 주요 변경 사항

- 카드 상세 창의 Date 버튼으로 마감일을 고르면 카드에 D-day가 표시됨 (마감이 지나면 빨간색)
